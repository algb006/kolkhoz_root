# Мануал проекта `core` — ядро симуляции на C++

Здесь техническая документация **ядра**: раскладка проекта, план текущей фазы и расчёты
баланса, с которыми сверяется прогон. Правила написания кода — в [`../CLAUDE.md`](../CLAUDE.md).
Операции с проектом коротко — в [`../README.txt`](../README.txt).

**Дизайн игры сюда не дублируется.** Он в мануале корневого проекта:
[`../../manual/`](../../manual/README.md).

| [`71-construction.md`](71-construction.md) | **Стройка** (вторая фаза, А2; **сдана 02.09.2026**). Площадка — строка юнита, `level 0` — «не построен»; четыре распоряжения за один шаг; ворота ссылкой, участок суммой радиусов; третий шов труда; секция сложенной пачки в сохранении одним подъёмом `VERSION_SAVE`; пять вопросов boss'у |
| [`plan/51-phase1-plan.md`](plan/51-phase1-plan.md) | **План первой фазы: ядро без графики.** Этапы, критерии готовности, что делаем и чего не делаем |
| [`balance/49-simulations.md`](balance/49-simulations.md) | **Сводка четырёх прогонов баланса.** Действующие цифры, с которыми должен сходиться прогон ядра |
| [`balance/69-reconciliation.md`](balance/69-reconciliation.md) | **Сверка прогона с расчётами.** Что сошлось, что нет и почему: цепочка по годам, дефекты ядра против канона, вопросы дизайну, таблица позиций, второй проход |
| [`balance/sim/`](balance/sim/) | Питоновские скрипты прогонов: `sim_v1.py` … `sim_v6.py`, `demography.py` |

Скрипты в `sim/` — прототипы на Python, а не часть сборки ядра. Они задают **эталонные числа**:
переписанная на C++ симуляция должна давать те же значения.

## Порядок этапов первой фазы

```
   0. Инфраструктура        сборка, форматирование        ← `setup/55-project-layout.md`
                            SSH и сборка под MSVC         ← `setup/60-windows-host.md`
   1. Скелет ядра           фазы, буферизация, планировщик, таблицы
                            модель состояния              ← `52-state-model.md`
                            цикл шага                     ← `53-step-cycle.md`
                            модули и зависимости          ← `54-modules.md`
                            формат таблиц                 ← `61-balance-tables.md`
   2. Время                 сутки, сезоны, световой день, скорости
   3. Жители                метрики, склонности, семьи, демография
   4. Земля                 поля, плодородие, урожай, склады
   5. Труд                  рабочий день, назначения, производительность
   6. Питание и ЛПХ         потребление, сытость, личные хозяйства
   7. Прогон и сверка       ImGui, графики, сравнение с расчётами
                            формат сохранений             ← `67-save-format.md`
                            ведомость прогона             ← `68-run-ledger.md`
```

Критерии готовности каждого этапа — в `plan/51-phase1-plan.md`.
