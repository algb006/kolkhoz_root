## 1. Решение: CSV, один диалект на весь конвейер

| Довод | |
|---|---|
| **Процесс балансировщика уже стоит на CSV** | «Правит в Google Sheets → экспорт → коммит» ([Технический дизайн §8](../../manual/technical/03-technical-design.md#8-данные-и-контент-пайплайн)). Ядро на JSON завело бы конвертацию на пустом месте |
| **UE импортирует CSV в `DataTable` штатно** | Один файл читают и ядро, и слой графики |
| **Наши данные по природе табличные** | Обобщённые сущности — «тип в таблице, не класс на случай». Вложенность не нужна: связи — ссылкой по `key`, реляционно |
| **Сотни параметров правятся в таблице удобнее** | JSON руками при балансировке — источник ошибок |
| Своё — нет | Выдуманный формат — худший из вариантов |

**Граница между базой и рукописным — по вопросу, на который отвечает число**
(формулировка boss, 31.08.2026): *если число отвечает на вопрос «как устроен мир», оно
принадлежит базе; если на вопрос «насколько сильно крутить» — рукописной таблице ядра.*
Урожайность коровы — как устроен мир. Скорость дрейфа сытости — насколько крутить. Этот
критерий работает и для чисел, которые не попадают ни в один реестр сущностей: норма
вспашки не принадлежит ни одной культуре и потому месяц пролежала рукописной, хотя по
смыслу дизайнерская.

**Источник файлов — база дизайна** (решение Кожаного 30.08.2026, реестр решений корневого
проекта; тред `design-db-source`). Реестры сущностей — ресурсы, культуры, скот, типы юнитов,
кормовые связи — **выгружаются из `~/kolkhoz/db/design.db` командой `tools/db.py csv` и
руками не редактируются**; диалект, правило `key` и `DefId = номер строки` остаются как
записаны ниже. Ключи сущностей принадлежат базе — свои не заводим. Скалярные балансные
таблицы ядра (`life.csv`, `labor.csv`, `farming.csv`, `campaign.csv`, `food.csv`, погода
и прочие ручки) в базе не живут и остаются рукописными. Правила перехода — §4а.

**Разграничение с constexpr.** «Таблицы на этапе компиляции» из [Архитектуры §7д](../../manual/technical/50-architecture.md#7д-требования-к-коду) — для
**структурного**: календарь, фазы, единицы измерения. Черта простая: **что крутится при
балансировке — в CSV, что определяет устройство симуляции — constexpr в коде.** Балансовая
правка не требует пересборки ([Архитектура §5](../../manual/technical/50-architecture.md#5-ресурсы-отдельно)).

## 2. Диалект

**RFC 4180 плюс три уточнения.** Канонический вид — тот, что лежит в репозитории.

| Правило | |
|---|---|
| Кодировка | **UTF-8 без BOM**, переводы строк LF (закреплено в `.gitattributes`) |
| Разделитель | **Запятая.** Десятичный знак — **точка** |
| Первая строка | **Заголовки колонок**, `snake_case` |
| **Строка с `#` в первой ячейке** | **Комментарий**, загрузчик выбрасывает. В Sheets это обычная строка — переживает круговой экспорт |
| Пустая ячейка | «Нет значения»: потребитель подставляет своё умолчание или объявляет ошибку конфигурации |
| Кавычки | Стандартные двойные, по RFC |

**Ловушка русской локали Sheets:** экспорт может дать точки с запятой и запятые в числах.
Канон — запятая-разделитель и десятичная точка; нормализация — забота будущего скрипта
импорта (инструменты, вторая фаза). Пока таблицы правятся прямо в репозитории.

## 3. Схема таблицы

| Правило | |
|---|---|
| **Колонка `key`** | Строковый идентификатор строки, `snake_case`. Обязательна в таблицах определений; уникальна — дубль валит загрузку |
| **`DefId` = номер строки** | Порядок строк в файле — это и есть плотный индекс ([`ids.h`](../include/core_common/ids.h)). Потолок — 65 535 строк |
| **Сохранения хранят ключи** | Переставили строки между запусками — загрузка сейва перепривяжет индексы по `key` |
| **Неизвестные колонки ядро игнорирует** | Балансировщик держит заметки и расчёты прямо в листе — это законно |
| **Нет обязательной колонки** | Ошибка загрузки, а не тихое умолчание |
| **Единица — в имени колонки** | `yield_kg`, `work_hours`, `ripen_days`, `weight_percent`. Пересчёт в внутренние единицы (граммы, тики) — на потребителе |

Пример (`tables/crops.csv`):

```csv
key,title,yield_kg_per_ha,ripen_days,labor_days_per_ha,fertility_delta
# зерновые
rye_winter,Рожь озимая,1100,44,24,-1
wheat_spring,Пшеница яровая,900,36,24,-3
# бобовые восстанавливают
pea,Горох,800,32,20,2
```

Числа в примере условные; настоящие придут из прогонов ([Симуляции](balance/49-simulations.md)).

## 4. Где лежат

**`tables/*.csv` в корне репозитория ядра; имя файла без расширения — имя таблицы.**
Список растёт по этапам: погода и световой день — этап 2, нормы потребления и демография —
этап 3, культуры, ресурсы, типы юнитов, виды скота — этап 4, ставки работ — этап 5,
еда и кормовые связи — этап 6.

## 4а. Генерируемые и рукописные таблицы

**Файл целиком либо генерируется из базы дизайна, либо пишется руками — смешанных нет.**

| Правило | |
|---|---|
| **Генерируемый файл начинается строкой-маркером** | `# generated from db/design.db — do not edit by hand`. Маркер есть — правка руками запрещена |
| **`tools/db.py csv` пишет прямо в `core/tables/`** | Ядро смотрит diff и коммитит: запись обмена — в репозитории ядра, как с любой правкой извне |
| **Таблица переводится на выгрузку, когда её обязательные колонки в базе заполнены** | До того лежит рукописная версия; переход по одной таблице, не разом |
| **Числовые балансные колонки живут в базе рядом с прозой** | Выгрузка механическая, прозу (`sow_window`) она не разбирает |
| **Полный реестр, а не срез фазы** | Строки будущих эпох приезжают тоже: `DefId` = строка, потолок 65 535, ядро лишние строки просто не использует |
| Комментарии в генерируемых файлах | Только из полей базы (`note`); рукописные якоря и ASSUMPTION — в рукописных таблицах |

## 5. Контракт чтения

**`core_tables` знает ячейки, а не домены.** `LoadTableSet` читает каталог целиком в
неизменяемый `ITableSet`; `ITable` отдаёт ячейки как текст, целое или вещественное.
Типизированные структуры определений каждая подсистема собирает **сама, на своей фабрике** —
разобранная таблица и есть та конфигурация, которую подсистеме держать разрешено
([модель состояния §1](52-state-model.md#1-главное-решение-состояние--данные-системы--логика)).

| Свойство | |
|---|---|
| **Загрузка целиком или никак** | Один битый файл — `nullptr` и внятная ошибка. Полузагруженный баланс хуже отсутствующего |
| **После загрузки неизменяем** | `PARALLEL_READONLY`: читают все фазы и потоки без синхронизации |
| **Правка на лету = перезагрузка** | Новый `LoadTableSet` → пересоздать симуляцию. Подсистемы состояния мира не держат, пересоздание стоит секунды — цикл балансировки из [Архитектуры §7в](../../manual/technical/50-architecture.md#7в-инструменты-разработчика) |

## 5а. Как читается ОДНО значение — у правила один дом (А6, 4 сентября 2026)

**`core_tables` отдаёт ячейку, `core_catalog` решает, что она значит.** Политика была написана
шесть раз; сведена в `core_catalog/table_value.h`.

| Ответ ячейки | Что значит | Что делает вызывающий |
|---|---|---|
| **`kRead`** | Есть, число, в диапазоне | Значение записано |
| **`kAbsent`** | **Нет строки, нет столбца или клетка пуста** | Своё умолчание — или отказ, если значение обязательно |
| **`kBad`** | **Есть и неверно** — не число либо вне диапазона | **Отказ конфигурации.** Полупонятый баланс хуже отсутствующего |

**Три ответа, а не два, и третий — тот, которого не было.** «Клетки нет» и «в клетке ноль» —
разные ответы, и пока они складывались в один, пустая клетка в присутствующем столбце `has_wear`
читалась как «этот юнит не изнашивается». **Замер: одна дыра в столбце останавливала старение
шести амбаров, и прогон при этом докладывал «all checks passed».** Теперь присутствующий столбец
обязан ответить за каждую строку, а пустая клетка в нём — отказ с именем строки.

### И вторая половина А6, 5 сентября 2026: дверь была построена и не до всех дошла

**Долг был записан как «пустая клетка неотличима от нуля».** При починке выяснилось, что
различение существует с 4 сентября — **не хватало не механизма, а его распространения.**

> **Правку начали с того, что стали заводить `CellState` второй раз, в `core_tables`. Остановил
> компилятор словом `redefinition`, а не автор.** То есть чинить «у факта два дома» собирались,
> заводя факту второй дом.

**Кто ходил мимо двери:**

| Модуль | Что было | Стало |
|---|---|---|
| **`core_time`** | четыре кустарных читателя — доля, температура, месяц, — каждый со своим диапазоном, написанные в тот же день | ходит через `core_catalog`; в `Range` добавлено `Unit()` (доля 0..1), потому что «0..1» у каждого вызова разъезжается по одному вызову за раз |
| **`genesis`** | `LayoutNumber` возвращал ноль на **три разных факта**: нет столбца, пустая клетка, текст не число | различает; **пустая — молча ноль (законна), не-число — предупреждение вслух** |

**Отказать `genesis` не может** — он строит мир и возвращает его. **Отказ живёт у разборщиков
конфигурации, а у раскладки своего разборщика нет**, и это записано открытым пунктом, а не залатано
наполовину.

**Проверяется через файл журнала:** предупреждение больше неоткуда наблюдать снаружи. Порчей
уронено в обе стороны — вернуть молчание на `12kg` и начать жаловаться на пустую.

> **Этаж выше — та же беда и тот же день:** набор таблиц БЕЗ погодной таблицы загружался без единого
> слова и шёл на заглушечных сезонах, так что целый день замеров описывал климат, которого в игре
> нет. **Отсутствующая таблица подменяет мир, отсутствующая клетка — величину.**

### Согласие на заглушку заявляет ВЫЗЫВАЮЩИЙ, а не подразумевает фабрика

**Печатью тут не обойтись, и довод — наш собственный:** сообщение, которого никто не прочёл, — не
сторож; проверка, которая не умеет провалиться, неотличима от отсутствующей.

> **Положение «иду на умолчаниях» обязано быть НЕОТКЛОНЯЕМЫМ для того, кто его не выбирал.**

`CreateTimeSystem` берёт вторым доводом `StubSeasons`, **и умолчания у довода нет**:

| Значение | Кто так говорит |
|---|---|
| **`kRefused`** | всякий, кто собирает игру. Набор без погодной таблицы — сломанный набор |
| **`kAllowed`** | юнит-тест и проба, которые строят подсистему без таблиц нарочно — **и говорят это вслух** |

**Цена — одно слово на месте вызова.** Оно покупает разницу между «таблицы такие, как я задумал» и
«таблицы такие, какими оказались».

**Замерено на себе: так вели себя ВСЕ ПЯТЬ фабрик подсистем** — время, стройка, труд, производство,
жители. Починена одна, заказанная; остальные четыре записаны открытым пунктом **числом**, потому что
число модулей и есть размер долга.

| Правило диапазона | |
|---|---|
| **Диапазон обязателен** | У знания «границ нет» есть запись — `Range::Any()`, — и это предложение в коде, а не пропуск |
| **Проверка пишется положительно** | `>= low && <= high`. **`NaN` сравнивается ложно со всем**, включая себя, поэтому отрицательная форма его пропускает. Так же отсекается бесконечность |
| **Потолок — не предел `float`** | `1e7`: всякое такое число попадает в сумму, приведение к целому или счёт граммов, и величина такого порядка уже означает, что таблица неверна |
